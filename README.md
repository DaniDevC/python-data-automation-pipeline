# Data Automation Pipeline in Python

Script de automatización en Python diseñado para procesar, limpiar y estructurar registros de datos (CSV) de forma desatendida. Incluye validación automática de campos, manejo de excepciones y generación de reportes consolidados.

## Características
- **Limpieza de datos:** Formateo automático de texto y saneamiento de valores numéricos.
- **Validación de errores:** Filtrado y omisión automática de registros corruptos o incompletos.
- **Generación de Reporte:** Exportación consolidada con fecha y hora de procesamiento.

## Uso
```bash
python pipeline.py datos_entrada.csv
